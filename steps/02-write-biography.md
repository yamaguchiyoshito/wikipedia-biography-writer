# 02. 構成・執筆

## 読み込む参照

[執筆規則](../references/writing-rules.md)、[出力形式](../references/output-format.md)、[執筆モード](../references/modes.md)、[文のリズム](../references/rhythm.md)を読む。指定されたモードに従い、構成と叙述の重心を調整する。

随想モードが指定された場合は、[随想モード](../references/essay.md)も読み、以下の「構成を決める」「原稿を書く」の代わりに、その構成・字数・資料注の規則に従う。

エピソード型が指定された場合は、[エピソード型](../references/episode.md)も読み、以下の「構成を決める」「原稿を書く」の代わりに、その構成・字数・資料注の規則に従う。

## 構成を決める

1. 作品を貫く問いを一つ設定する。指定された問いを資料が支えない場合は、資料で扱える範囲へ絞る。
2. その後の行動や立場を変えた転機を3〜5個選ぶ。有名さより、人生の変化を説明できることを優先する。資料が少ない場合は数を減らす。
3. 問いと転機を中心に、3〜6章程度の構成を作る。指定文字数と資料量に応じて章数を調整する。

問いの候補は「評価される前後の変化」「組織への所属と独立の緊張」「功績と損失の関係」「生前と後世の評価の違い」など。資料にない葛藤や代償は設定しない。

## 原稿を書く

次の流れを基本とし、対象人物と資料に合わない場合は変更する。

| 位置 | 書く内容 |
| --- | --- |
| 冒頭 | 選択や立場が表れる、記録のある出来事から始める。情景の細部が不足する場合は、事実や対照から始める |
| 前半 | 必要な過去に戻り、その地点に至る環境・関係・初期の活動を描く |
| 中盤 | 転機ごとに「状況→行動・選択→周囲の反応→結果→次の行動への影響」を、資料で確認できる範囲で描く |
| 後半 | 到達点に加え、資料にある限界・対立・未達成・評価の相違を描く |
| 結末 | 可能なら冒頭の事実に立ち返り、人生を読んだ後では意味が変わる形で閉じる |

各転機を同じ型に無理に当てはめない。本人の決断と、他者・環境によって起きたことを区別する。

転機は詳しく、間の期間は要約する。中心の問いに関係しない年月日・肩書・作品名の羅列を避ける。

存命人物は資料で追える時点までを描き、人生が完結したように総括しない。

## 次の手順へ渡すもの

原稿、出典・資料注、事実と出典の対応メモを用意する。構成案や対応メモは最終出力に含めない。
