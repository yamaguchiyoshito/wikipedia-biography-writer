# 03. 検証・出力

## 読み込む参照

[執筆規則](../references/writing-rules.md)と[出力形式](../references/output-format.md)を読む。

## 検証して修正する

- [ ] 年月日、出来事、引用、場面の細部を、実際に読んだ資料へ対応付けられる。
- [ ] 未読の文献を出典にせず、記事の不確実性や資料間の矛盾を隠していない。
- [ ] 内面・動機・因果関係を根拠なく断定せず、架空の会話や情景を加えていない。
- [ ] 物語に都合の悪い重大な事実や反証を落とさず、疑惑・批判と確定事実を区別している。
- [ ] 記事の文章や見出しをなぞらず、中心の問いと転機で構成している。
- [ ] 本文に「Wikipediaによれば」「典拠とするのは」「〜に依拠した記述」「記事にはそうある」「記事は語らない」「書かれていない」など、資料の依拠関係や取得経路を語る文がない（あれば削除し、人物を主語にした直接叙述へ書き換え、出典の話は出典・資料注へ移す。随想・エピソード型も対象）。
- [ ] 人物評価を具体的な行動で示し、人生を後知恵による必然の物語にしていない。
- [ ] 名前を別人に置き換えても成立するような定型的な美談・教訓で終えていない。
- [ ] 存命人物の扱い、資料の対象時点、字数不足の理由を必要に応じて示している。
- [ ] 文のリズム（[文のリズム](../references/rhythm.md)）：読点が少なめ（短・中文は0〜1個、長文でも2個まで、読点のない文が段落の半数以上）で、同じ長さ・同じ文末の3連続、息の続かない長文がない。各章に短文と長文の振れ幅があり、同じ文頭型が4文続かず、単調でない。モードに応じた強度で調整している。作家の模倣や、リズムのための事実の変更をしていない。
- [ ] 指定された執筆モードに沿っており、モードを理由に事実の創作や不確実性の隠蔽をしていない。
- [ ] エピソード型の場合（[エピソード型](../references/episode.md)）：焦点の出来事が資料に記録されており、生涯の通史や無関係な経歴の列挙になっていない。導入・展開・余波・結末が揃い、教訓や人生の総括で閉じていない。
- [ ] 随想モードの場合（[随想モード](../references/essay.md)）：冒頭に対象人物の名前がなく、語り手の体験から始まっている。創作は語り手側に限られ、人物の事実（年・出来事・数値・引用）は資料に対応する。想像は想像と分かる形で書かれている。結末が一文で余韻を残し、教訓・総括で閉じていない。最後の一文が語り手の体験・感想でなく、対象者についての語であり、かつ事実報告に終わらず像や印象が残る。年・日付が本文全体で3〜5か所までに絞られ、経歴の年代順の羅列になっていない。本文の中ほどにも、人物の事実から取った、余韻のある短い一文が1〜2か所あり、余韻が結末だけに偏っていない。出典・資料注に、創作部分と事実部分の区別がある。
- [ ] 出典・資料注が揃い、指定の文体・文字数・出力形式に沿っている。

裏付けのない記述は削除するか、確認できる事実に置き換える。不確実性自体が重要な場合は、その内容と根拠を明示する。

## 出力する

[出力形式](../references/output-format.md)に従い、タイトル、本文、出典・資料注を出力する。

作業報告、構成案、整理表、検証チェックリスト、自己評価は出力しない。
