# 01. 資料確認

## 読み込む参照

[執筆規則](../references/writing-rules.md)を読む。

## 入力を確定する

指定済みの情報は再質問しない。任意項目が未指定の場合は、次の既定値を使う。

| 項目 | 指定内容・既定値 |
| --- | --- |
| 対象人物 | 未指定なら入力記事から判断する |
| 資料 | WikipediaのURLまたは記事本文。複数指定可 |
| 補助資料 | 任意。未指定ならWikipediaの記事のみを使う |
| 形式 | 伝記型（生涯全体）。エピソード型（一つの出来事に焦点）も指定可（[エピソード型](../references/episode.md)） |
| 描く範囲 | 伝記型は生涯全体。エピソード型は焦点とする出来事（未指定なら資料から選ぶ） |
| 中心の問い | 資料から最も根拠を持って描ける問いを一つ選ぶ |
| 想定読者 | 対象人物に詳しくない一般読者 |
| 本文の目安文字数 | 6,000字。資料が不足する場合は短くする |
| 文体 | 日本語・常体。落ち着いた、抑制の利いた文章 |
| 執筆モード | 標準。文学性重視・史実重視も指定可（[執筆モード](../references/modes.md)） |

## 資料を読む

1. URL指定の場合は、利用可能な取得手段で記事本文を読む。検索結果の抜粋だけで記事を読んだことにしない。
2. 本文が提供されている場合は、その本文を使う。見えていない部分を記憶や推測で補わない。
3. 記事名、URL、実際の参照日、使用した節を記録する。貼り付け本文で不明な情報は作らない。
4. 補助資料は、ユーザーが指定したものに限り、実際に読めた範囲で使用する。未読の脚注文献は直接参照した出典に数えない。
5. 一部の資料を取得できなくても、読めた資料で進められる場合は続行し、利用できなかった資料と制約を資料注に残す。

資料が未指定、または利用可能な本文が一つもない場合は、執筆を止めて記事本文の提供を求める。

## 作業用の資料メモを作る

次の項目を、出典の位置と対応付けて整理する。これは最終出力に含めない。

- 主要な出来事：時期、行動、周囲の反応、結果、その後の変化。
- 行動を可能にした条件と制約：制度、経済状況、家族、所属組織、支援者、対立者。
- 不確実な記述：異説、出典不足、資料間の矛盾、評価の相違。

動機や因果関係は、資料に記述がある場合だけ事実として整理する。執筆者の解釈は区別する。
