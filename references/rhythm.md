# 文のリズム

文体を変えずに、読みやすさを生む文の呼吸を整える。語彙、比喩、人称、口調は変えない。

## 規則

### 句読点

- 読点は、音読して息継ぎが自然な位置に打つ。意味の切れ目と、息の切れ目を合わせる。
- **読点は少なめにする**。短文・中文（40字以内）は0〜1個、長文でも2個までとする。3個以上は文を分ける。
- 読点を省く位置：主語直後（「彼は、」→「彼は」）、短い接続語の直後（「だが、」→「だが」）、短い時や場所の語句の直後（「1942年、」→「1942年に」）、「と」「や」で足りる並列。
- 読点を残す位置：誤読を防ぐ場合、長い主語や修飾の切れ目、意味の大きな転換。
- 同一段落で、読点のない文が少なくとも半数を占めるようにする。
- 長い修飾語は、語順を入れ替えるか、文を分けて、修飾先との距離を縮める。
- 1文に入れる事実は1〜2点を目安とする。人名・地名・作品名を一文に並べない。

### 文の長さと文末

- 短い文と長い文を混ぜる。重要な事実や転機は、短い文で置く。
- 同じ長さの文が3つ続かないようにする。
- 同じ文末（「〜た。」「〜いる。」）が3回続かないようにする。常体の範囲で、現在形、体言止め、否定、倒置を混ぜる。
- 体言止めは、1段落に1回までとする。

### 変化をつける（単調さの回避）

「短文と中文が交互に並ぶ」だけでは、規則的で単調になる。次で、強弱の差を作る。

- **長さの振れ幅**：各章に、15字以内の短文と、60〜90字の長文を、それぞれ1つ以上入れる。中間の長さ（25〜45字）だけで章を埋めない。
- **長文の使いどころ**：連続する出来事や、一息で通したい経過（移動、制度の流れ、因果の連鎖）は、1文で流す。長文は読点を2つまでに抑え、主語と述語の距離を縮める。
- **短文の使いどころ**：転機、断定できる事実、段落の末尾に置く。1章に3回までとし、連打しない。
- **文頭の変化**：「〜は、〜した。」の主語始まりを4文続けない。時、場所、対象、接続（「だが」「そのあと」）、条件、倒置、引用の一部から、文を始める。
- **段落の形を揃えない**：隣り合う段落で、文数と、最初・最後の文の長さが同じにならないようにする。1文だけの段落を、章に1つまで使ってよい。
- **叙述の種類を混ぜる**：経過の叙述、数値や日付の事実、引用の一部、読者への問いを、章の中で混ぜる。ただし問いは、全体で3回までとする。
- **密度の落差**：転機は短い文で細かく刻み、間の期間は長文で一息に流す。同じ章内で、速い箇所と遅い箇所を作る。

### 段落

- 1段落は3〜6文を目安とする。
- 転機の直前または直後には、1〜2文の短い段落を置いてよい。
- 段落の最後の文は、次の段落へ向かう間として働かせる。結論や教訓で締めない。

### 読み返し

- 完成前に、全文を音読する気持ちで読み、つかえる箇所、息が続かない箇所、同じ調子が続く箇所を直す。
- 各章について、文の長さを順に並べて確認する。最短と最長の差が小さい、中間の長さが4文以上続く、同じ文頭型が4文続く場合は、文を結合・分割して直す。

## 禁止事項

- 特定の作家に似せた語彙、比喩、口調、人称を使わない。作家名や文体の模倣を、本文や資料注に書かない。
- リズムのために、事実を足したり、削って意味を変えたり、因果を付け加えたりしない。
- 短文の連打で、劇的さを演出しない。

## モードごとの強度

| モード | 強度 |
| --- | --- |
| 文学性重視 | 強い。長短の配置、段落の間、文末の変化を積極的に調整する |
| 標準 | 中程度。連続する同形の文と読点の過多を直す |
| 史実重視 | 最低限。事実の並びが読みにくい箇所と、読点の過多だけを直す |
