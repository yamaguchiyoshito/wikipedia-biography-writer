# 出力形式

最終出力は、タイトル、本文、出典・資料注の順とする。前置きや作業報告は付けない。

## 形式

```markdown
# ［人物名］――［人生を貫く問いや対照を示す題名］

## ［第1章の見出し］

［散文の本文］

## ［第2章以降の見出し］

［散文の本文。資料量に応じて章を追加する］

## 出典・資料注

［使用資料、各章との対応、引用の出典、不確実性、資料上の制約］
```

## 本文

- 題名は人物固有の問いや対照を表し、根拠のない煽り文句を使わない。
- 随想モードでは、章見出しを省き、題名に人物名を使わなくてよい（[随想モード](essay.md)）。
- エピソード型の本文は2〜4章、題名は「人物名――出来事を示す語句」とする（[エピソード型](episode.md)）。
- 本文は3〜6章程度の散文を基本とし、資料量と指定文字数に合わせて調整する。
- 本文に箇条書きや表を使わない。見出しと段落で構成する。
- 直接引用、重要な異説、判断が分かれる主張には、本文でも対応する注または利用環境の引用機能を使う。
- 本文に、資料の取得経路、Wikipediaの記述の依拠関係、典拠の限界を述べる文を入れない（例：「Wikipediaがこの経緯の典拠とするのは」「この経緯はWikipedia上では一冊の著作に依拠した記述であり、細部は確定した事実として扱えない」）。これらは出典・資料注へ移す。

## 出典・資料注

次を簡潔に記載する。必要な場合は箇条書きを使ってよい。

1. 実際に使用した記事名、URL、実際の参照日。補助資料を使った場合はその情報。
2. 各章の主要な出来事に対応する、記事の節名や補助資料の位置。
3. 引用の出典。Wikipedia経由の引用なら、原典を直接確認したように書かない。
4. 重要な異説、資料間の不一致、確実性に関する留保。
5. 利用できなかった指定資料、描けなかった期間、資料不足による文字数縮小などの制約。

提供本文しか使っておらず、記事名・URL・参照日が不明な場合は、分かる情報だけを示し「提供された記事本文を使用」と記載する。実際の閲覧日時や出典情報を捏造しない。

構成案、作業用の資料メモ、検証チェックリスト、自己評価は含めない。
