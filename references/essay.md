# 随想モード

人物そのものではなく、人物に触れた「私」のパーソナルな体験から書き始め、人物の事実へ静かに渡していくモード。伝記ではなく、人物をめぐる短い随想として書く。

## 他のモードとの違い

このモードに限り、**語り手の体験・状況は創作してよい**。ただし創作できるのは語り手側の場面だけで、人物に関する事実は、他のモードと同じく実際に読めた資料に限る。

| 区分 | 扱い |
| --- | --- |
| 語り手（「私」または無名の「青年」「彼女」など）の状況・情景・感覚 | 創作してよい |
| 人物の生没年・出来事・作品・数値・引用・評価 | 資料にあるものだけ。創作・脚色・補完をしない |
| 人物の内面や、資料にない場面 | 事実として書かない。書く場合は「〜だったのかもしれない」「もし〜だったなら」など、想像と分かる形にする |
| 引用 | 資料で確認できるものだけ。出典不明の名言を人物の言葉として書かない |

語り手の体験を人物の事実と取り違えさせる書き方（創作した出来事を、人物の経歴として断定的に書くこと）はしない。

## 構成

- 冒頭：人名（対象人物の名前）を出さない。五感に触れる具体的な瞬間や、短い一文で始める。
- 中盤：語り手の体験と、人物の事実（記録のある出来事・作品・言葉）を、行き来しながら重ねる。人物の名前は、ここで初めて出してよい。説明で重ねず、対照や響き合いで重ねる。
- 中程の一文：**本文の中ほど（人物の事実を重ねている区間）に、ハッとさせる一文を1〜2か所置く。**余韻が最後の一文にしかない状態にしない。人物の事実のなかから、読者が一拍止まる像を選び、短い独立した一文（または一行の段落）として、前後から切り離して置く。例：転機の一瞬、残された物、失われたもの、沈黙、数字の持つ重さ。説明や感想を足して意味を閉じない。語り手の感想で代用しない。事実は資料の範囲に限り、飾るための想像は足さない。
- 結末：**最後の一文は、対象者についての語りにする。**語り手の体験・感想・動作で閉じない（語り手は冒頭から中盤までに退く）。資料にある対象者の事実、情景、行為、残されたものを、教訓・総括・結論を言わず、解釈を閉じずに置いて止める。単なる事実の報告（日付・数値・肩書き・完了通知）で終えず、読後に印象が残る一文にする。具体的な物・情景・行為・沈黙・未完の状態など、像が浮かぶ要素を選び、対象者の事実の範囲で置く。結びは「AをBに収めた」「AだったものがBになった」のような、対比で綺麗にまとめる型にしない。まとめず、静止した情景、見えないもの、不在、沈黙、まだ動いている状態のどれかを置き、読者が最後に一拍、立ち止まれるようにする。余韻は一文で残す。
- 題名：人物名を使わなくてよい。象徴的な語句にする。
- 章見出しは不要。本文は、場面の転換ごとに行を空けた段落でよい（空行は区切りとして使う）。

## 文体と分量

- 常体。短い文と、息の長い一文を混ぜる。
- 詩的な表現は、具体物や感覚に根差したものに限る。定型的な美辞麗句、抽象的な標語は使わない。
- 疑問文は2回まで。読者に問う形で、答えを本文で言い切らない。
- 本文の目安は800〜1,800字。引き延ばさない。
- 年・日付は絞る。経歴を年代順に並べず、年を書くのは、場面に意味のある数点（転機・生没など）に限り、目安は本文全体で3〜5か所まで。それ以外は「その後」「十三歳の彼は」「のちに」など、年を書かない言い方にする。履歴書のように、出来事を年とともに連ねない。取り上げる事実も、語り手の場面と響き合うものに絞り、網羅しない（省略は資料注に書く）。
- [文のリズム](rhythm.md)は強く適用する。特に、結末の一文は短く、余白が残る長さにする。

## 出典・資料注

出典・資料注は、本文の後に必ず付ける。次を記す。

- 創作した部分（語り手の状況・情景・感覚）と、それが創作であること。
- 事実として書いた部分と、対応する記事の節。
- 想像として書いた箇所（人物の内面など）があれば、その箇所と、想像であること。
- 資料にない人物像を、事実として書いていないこと。

## 併用

- 伝記型・エピソード型の両方と併用できる。ただし随想モードでは、章立てと字数を随想の規則が優先する。
- 他のモード（文学性重視・史実重視）とは併用しない。随想モード自体がリズムと余韻を重視するため、指定が重なった場合は随想モードを優先する。

## 禁止

- 人物の事実の創作。出来事・年・数値・引用を、書きやすさのために変えること。
- 語り手の体験を、人物の事実の裏付けとして使うこと。
- 結末で、教訓・結論・感想の宣言をすること。
- 最後の一文を、語り手の体験・感想・動作（「私は〜した」など）で閉じること。
- 最後の一文を、印象の残らない事実報告（「〜年に完了が報告された」など）で終えること。
- 本文に、資料の依拠関係を語る文言（「記事にはそうある」「記事によれば」「書かれていない」など）を入れること。人物の事実は、人物を主語に直接叙述する。
