# エピソード型

人生全体ではなく、一つの出来事（エピソード）に焦点を当てて書く形式。執筆モード（標準／文学性重視／史実重視）とは独立した軸で、組み合わせて使う。

## 指定例

「エピソード型で」「一つの出来事に絞って」「○○の場面だけ」「△△事件を中心に」。出来事を指定しない場合は、資料から最も記録が厚く、人物の選択が表れた出来事を一つ選ぶ。

## 共通の不変条件

[執筆モード](modes.md)の不変条件をすべて守る。さらに次を守る。

- 焦点の出来事は、実際に読めた資料に記録のあるものに限る。
- 前後の人生は、出来事を理解するのに必要な範囲だけを書く。
- 資料にない場面・会話・内面を創作しない。時間を圧縮しても、記録された順序と日付は変えない。

## 焦点の選び方

1. 人物の選択・決断・失敗が表れ、前後で状況が変わった出来事を選ぶ。
2. 日付・場所・関与者・結果が、資料から追える出来事を優先する。
3. 資料が薄く、数行しか記録のない出来事は、無理に長く書かず、描ける範囲に絞る。その場合は文字数を縮める。

## 構成

| 位置 | 書く内容 |
| --- | --- |
| 導入 | 出来事の直前または最中の、記録のある瞬間から始める。人物の生涯の紹介から入らない |
| 背景 | その出来事に必要な過去・環境・関係だけを短く戻って描く。生涯の通史にしない |
| 展開 | 出来事を、時系列に沿って、記録のある行動・反応・結果で描く。叙述を最も厚くする |
| 余波 | その後の影響を、資料で確認できる範囲で短く描く。生涯の総括にしない |
| 結末 | 導入の瞬間や事実に戻る。教訓や人生の総括で閉じない |

- 章は2〜4章を基本とし、本文の目安は3,000〜4,000字とする。ユーザーが文字数を指定した場合はそれに従う。
- 題名は「人物名――出来事を示す語句」の形にする。
- 出来事に関係しない経歴・作品・肩書の列挙は、一行でも入れない。生涯の大半は省いてよい。

## 資料注での扱い

- 焦点とした出来事と、選んだ理由を一行で示す。
- 省いた生涯の主要部分は、省いたことを一括で示せばよい（個々の列挙は不要）。
- 出来事の確実性と、異説・資料間の不一致は、通常どおり記す。
- 字数が目安に満たない理由（資料不足）を記す。

## 他のモードとの併用

- 文学性重視：導入と結末の対応、場面ごとの対比、リズムを強める。
- 史実重視：出来事の経過を、時刻・日付・関与者まで細かく時系列で示す。異説は本文で併記する。
- 標準：均衡を基準にする。

併用時も、事実の創作や不確実性の隠蔽はしない。
