# wikipedia-biography-writer

WikipediaのURLまたは記事本文から、事実に基づく日本語の伝記文学を書くスキル。

詳しい使い方は [ユーザーガイド](docs/user-guide.md) を参照。

## 使い方

```
https://ja.wikipedia.org/wiki/○○ から伝記を書いて
```

## 構成

- `SKILL.md`：スキル定義・実行手順の入口
- `steps/`：資料確認 → 構成・執筆 → 検証・出力
- `references/`：執筆規則・出力形式・執筆モード・エピソード型
- `docs/user-guide.md`：ユーザー向けガイド
- `examples/`：出力例（良出来のものに限る）
