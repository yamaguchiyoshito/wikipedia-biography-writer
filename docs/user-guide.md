# ユーザーガイド

## できること

Wikipediaの人物記事から、人物の選択・制約・転機を軸にした日本語の伝記文学（ノンフィクション型の散文）を作成します。

**向かない依頼**：記事の要約、年表の作成だけが目的の場合。

## 入力

必須は次のどちらかです。

- WikipediaのURL（複数可）
- 記事本文の貼り付け

資料が読めない・未指定の場合、執筆せず本文の提供を求められます。

## 任意の指定

指定しなければ既定値が使われます。

| 項目 | 既定値 |
| --- | --- |
| 対象人物 | 入力記事から判断 |
| 補助資料 | なし（Wikipediaのみ） |
| 描く範囲 | 生涯全体 |
| 中心の問い | 資料から最も根拠を持って描ける問い |
| 想定読者 | 人物に詳しくない一般読者 |
| 文字数 | 本文6,000字（資料不足なら短くなる） |
| 文体 | 日本語・常体、抑制の利いた文章 |

## 依頼例

```
https://ja.wikipedia.org/wiki/○○ から伝記を書いて
```

```
次の記事本文から伝記文学を書いて。青年期から晩年まで、4,000字、中学生向け。
（本文を貼り付け）
```

## 出力

タイトル、3〜6章程度の本文、「出典・資料注」の順で出力されます。前置きや作業メモは付きません。

出典・資料注には、使用資料、参照日、章ごとの根拠、異説・不確実性、使えなかった資料などの制約が記載されます。

## 事実の扱い

- 実際に読めた資料の内容だけを使います。
- 資料にない出来事・会話・内面・情景は創作しません。
- 貼り付け本文だけの場合、不明な記事名・URL・参照日は捏造されません。
- 補助資料はユーザーが指定し、実際に読めたものに限ります。
