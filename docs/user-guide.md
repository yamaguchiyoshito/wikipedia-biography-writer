# ユーザーガイド

## できること

Wikipediaの人物記事から、人物の選択・制約・転機を軸にした日本語の伝記文学（ノンフィクション型の散文）を作成します。

**向かない依頼**：記事の要約、年表の作成だけが目的の場合。

## 入力

必須は次のどちらかです。

- WikipediaのURL（複数可）
- 記事本文の貼り付け

資料が読めない・未指定の場合、執筆せず本文の提供を求められます。

## 任意の指定

指定しなければ既定値が使われます。

| 項目 | 既定値 |
| --- | --- |
| 対象人物 | 入力記事から判断 |
| 補助資料 | なし（Wikipediaのみ） |
| 形式 | 伝記型（生涯全体） |
| 描く範囲 | 生涯全体（エピソード型は焦点の出来事） |
| 中心の問い | 資料から最も根拠を持って描ける問い |
| 想定読者 | 人物に詳しくない一般読者 |
| 文字数 | 本文6,000字（資料不足なら短くなる） |
| 文体 | 日本語・常体、抑制の利いた文章 |
| 執筆モード | 標準（文学性と史実性の均衡） |

### 執筆モード

| モード | 依頼例 | 特徴 |
| --- | --- | --- |
| 標準 | （指定なし） | 均衡 |
| 文学性重視 | 「文学的に書いて」 | 対比・リズム・構成を強め、事実を絞る |
| 史実重視 | 「史実重視で書いて」 | 年月日・出来事を広く扱い、異説も本文で併記 |
| 随想 | 「随想で書いて」 | 冒頭に人名を出さず、語り手の体験から入る。語り手の状況は創作可、人物の事実は資料のみ。年・日付は絞り、経歴を羅列しない。中ほどにも余韻のある一文を置く。最後の一文は対象者についての語りで、印象と余韻を残す |

随想モードでは、出典・資料注に、創作した部分と事実の部分を区別して記します。

どのモードでも、人物に関する事実の創作はしません。文は、読点・長短・段落の呼吸を整えて読みやすく仕上げます（文体は変えません）。

### 形式

| 形式 | 依頼例 | 特徴 |
| --- | --- | --- |
| 伝記型 | （指定なし） | 生涯を、問いと転機で貫く（3〜6章） |
| エピソード型 | 「エピソード型で」「○○事件に絞って」 | 一つの出来事に焦点。前後は必要な範囲のみ（2〜4章、3,000〜4,000字目安） |

形式とモードは独立に組み合わせられます（例：エピソード型×文学性重視）。出来事を指定しなければ、資料から選びます。

## 依頼例

```
https://ja.wikipedia.org/wiki/○○ から、○○事件に絞ったエピソード型で、文学性重視で書いて
```

```
https://ja.wikipedia.org/wiki/○○ から伝記を書いて
```

```
次の記事本文から伝記文学を書いて。青年期から晩年まで、4,000字、中学生向け。
（本文を貼り付け）
```

## 出力

タイトル、3〜6章程度の本文、「出典・資料注」の順で出力されます。前置きや作業メモは付きません。

出典・資料注には、使用資料、参照日、章ごとの根拠、異説・不確実性、使えなかった資料などの制約が記載されます。

## 事実の扱い

- 実際に読めた資料の内容だけを使います。
- 資料にない出来事・会話・内面・情景は創作しません（随想モードの語り手の体験を除く）。
- 貼り付け本文だけの場合、不明な記事名・URL・参照日は捏造されません。
- 補助資料はユーザーが指定し、実際に読めたものに限ります。
